# Originele paspoortaanvragen

Plaats hier de volledige, ongewijzigde scans van paspoortaanvragen. Bewaar de originele resolutie en bestandsnamen. Voor- en achterzijde als afzonderlijke bestanden. Niet bijsnijden of opnieuw comprimeren.

De webpagina toont deze bestanden integraal; losse portretuitsneden komen in `../pasfotos/`.
