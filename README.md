# Nederlands-Indië | Historisch Fotoarchief

Statische GitHub Pages-site met een live doorzoekbare fotogalerij via de Wikimedia Commons API en links naar primaire beeldarchieven.

## Onderdelen
- Nederlands-Indië algemeen
- Java en plaatsgerichte zoekfilters
- Uitgebreide Bandoeng/Bandung-sectie
- KNIL & militaire geschiedenis
- Dagelijks leven
- Filters voor periode en onderwerp
- Bron- en licentielinks per Wikimedia-afbeelding

## Publiceren
1. Ga naar **Settings → Pages**.
2. Kies **GitHub Actions** als deployment source.
3. De workflow publiceert automatisch na een push naar `main`.
4. De website is daarna beschikbaar op `https://manuelbirsak-web.github.io/nederlands-indie-fotoarchief/`.

## Beeldrechten
Afbeeldingen worden live van Wikimedia Commons geladen en niet naar deze repository gekopieerd. Per afbeelding opent de originele bestandspagina met maker, bron en licentie. Controleer licentievoorwaarden vóór hergebruik. Links naar andere archieven openen de oorspronkelijke collectiepagina's.

## Beperkingen
Dit is een doorzoekbare startcatalogus, geen volledige kopie van alle bestaande archieven. Niet alle archieven bieden een openbare API of toestemming voor herpublicatie. De catalogus kan worden uitgebreid met gecontroleerde metadata en extra collectie-integraties.
